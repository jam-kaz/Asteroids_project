## Описание проекта
Программа представляет собой двумерную космическую аркадную игру «Астероиды», реализованную на языке Python с использованием библиотеки `pygame`. Игрок управляет космическим кораблем в тороидальном пространстве, уклоняется от астероидов и уничтожает их ракетами. Реализована физика инерции с сопротивлением среды, параллакс-эффект динамического фона и тайловая покадровая анимация взрывов.

## Функциональные возможности
### Основной функционал
- Управление кораблем: вращение, ускорение с анимацией тяги двигателя и инерционное торможение.
- Тороидальная геометрия игрового поля (бесшовный переход объектов через границы экрана).
- Стрельба ракетами с ограниченным временем жизни и расчет столкновений.
- Тайловая покадровая анимация взрывов при уничтожении астероидов и столкновениях.
- Многослойный фон: статичный космос и полупрозрачный динамический слой астероидов.
- Подсчет очков, система жизней и экран заставки с перезапуском сессии по клику.

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** pygame==2.6.1

## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone https://github.com/jam-kaz/Asteroids_project.git
cd asteroids-game
```

### 2. Создание и активация виртуального окружения
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление
- **ЛКМ по заставке** — старт / перезапуск игры
- **Стрелка влево / вправо** — вращение корабля
- **Стрелка вверх** — включение двигателя (ускорение)
- **Space (Пробел)** — выстрел ракетой

## Структура проекта
```text
asteroids_project/
├── .gitignore          # Исключения для Git (папка venv не исключена по требованию)
├── README.md           # Документация проекта
├── requirements.txt    # Список зависимостей
├── main.py             # Точка входа в программу
└── src/
    ├── __init__.py
    ├── config.py       # Глобальные параметры и константы игры
    ├── assets.py       # Генератор графических спрайтов и тайлового листа
    ├── entities.py     # Классы игровых объектов (Ship, Asteroid, Missile, Explosion)
    └── game.py         # Игровой цикл, обработка событий, физика и отрисовка
```

**Назначение основных модулей:**
- `main.py` — инициализация и запуск приложения.
- `src/config.py` — хранение всех настроек экрана, скоростей, таймеров и размеров.
- `src/assets.py` — программная генерация спрайтов и нарезка тайлового листа взрыва.
- `src/entities.py` — объектно-ориентированная модель сущностей и математика движения.
- `src/game.py` — управление состояниями игры, коллизиями и слоями рендеринга.
